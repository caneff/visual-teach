BPMN

Hand-built SVG, true BPMN notation — who hands what to whom, across actors. No JS: each diagram is static SVG authored per lesson.

Notation rules

  • The gateway diamond (.vt-bpmn-gateway) holds only its marker — × for exclusive — never the question.
  • The question that decides the branch labels the gateway from outside, as a .vt-bpmn-flow-label above it.
  • Each outgoing flow gets its own yes / no label; XOR branches run side by side, never stacked.
  • The start event (.vt-bpmn-event) is a thin circle; the end event adds .end for a thick one.
  • A wide diagram scrolls inside its .vt-bpmn wrap (overflow-x: auto) instead of shrinking to mush.
  • The <svg> carries role="img" and an aria-label summarizing the whole diagram — the SVG parts carry no text alternative of their own.

Three-lane process

Real BPMN notation: thin/thick event circles, a marker-only gateway diamond, and drawn cross-lane flows — XOR branches (no / yes) run side by side. Wide at 860px, so the .vt-bpmn wrap scrolls rather than shrinking.
