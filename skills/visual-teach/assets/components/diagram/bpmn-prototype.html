BPMN block — prototype

Same process three ways: how base.js wires a lesson's interactive blocks. Flip with the bar below or ←/→.

A — Mermaid, subgraphs as lanes

flowchart TD
  subgraph browser[Browser]
    S([DOMContentLoaded fires])
  end
  subgraph basejs[base.js]
    scan[Scan DOM for vt-* blocks]
    g{Required children present?}
    warn[console.warn, leave block inert]
    wire[Wire behavior + listeners]
  end
  subgraph comp[Component JS]
    ann[Announce state via live region]
    E([Lesson interactive])
  end
  S --> scan --> g
  g -- no --> warn
  g -- yes --> wire --> ann --> E

Cheapest to author — the agent emits mermaid text. Lanes are subgraphs, so vertical, not true swimlanes.

E — bpmn-js viewer, bpmn-auto-layout DI

Real bpmn-js rendering XML laid out by bpmn-auto-layout at build time. Caveat: auto-layout emits no DI for the pool/lanes, so the swimlanes vanish — the flow renders flat.
