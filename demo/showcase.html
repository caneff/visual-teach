BPMN

Hand-built SVG, true BPMN notation — who hands what to whom, across actors. No JS: each diagram is static SVG authored per lesson.

Notation rules

  • The gateway diamond (.vt-bpmn-gateway) holds only its marker — × for exclusive — never the question.
  • The question that decides the branch labels the gateway from outside, as a .vt-bpmn-flow-label above it.
  • Each outgoing flow gets its own yes / no label; XOR branches run side by side, never stacked.
  • The start event (.vt-bpmn-event) is a thin circle; the end event adds .end for a thick one.
  • A wide diagram scrolls inside its .vt-bpmn wrap (overflow-x: auto) instead of shrinking to mush.
  • The actor labels are an HTML .vt-bpmn-lanes rail, not SVG text: it pins to the left edge while the diagram scrolls. Give each <span> flex: <its lane's height in svg units> so the rail tracks the lane fractions at any scale, start the viewBox x at the rail width (34), and mark the rail aria-hidden — the lanes are named in the aria-label.
  • The <svg> carries role="img" and an aria-label summarizing the whole diagram — the SVG parts carry no text alternative of their own.
  • The arrowhead id is fixed: .vt-bpmn-flow points marker-end at #arrow, so each diagram defines that <marker> in its own <defs> — and two diagrams on one page share the first one. Copy the <defs> block below verbatim.
  • Optional breakout, still no JS: give the inline <svg> an id, add a .vt-bpmn-expand button with popovertarget, and a .vt-bpmn-pop [popover] holding <use href="#that-id">. The popover opens in the top layer at up to 96vw — outside any column. Keep the original's viewBox/width/height on the copy: a narrow diagram scales up to fill, and one wider than the screen never shrinks below natural size — it scrolls inside the breakout. Esc or clicking outside closes it. Both ids must be unique per page.

fibonacci.py 
def fibonacci(n):
    """Return the nth Fibonacci number."""
    if n <= 1:
        return n
    a, b = 0, 1
    for _ in range(2, n + 1):
        a, b = b, a + b
    return b

# Print first 10 Fibonacci numbers
for i in range(10):
    print(f"fib({i}) = {fibonacci(i)}")

Reveal

Free-recall prompts that hide their answer until clicked. Built on native <details> — no JS. Use for active recall, where the learner produces the answer from memory, then checks it; reach for quiz instead when you want checked recognition from fixed options.

Retrieval is what makes it stick — try each before revealing.

What two parents does a merge commit have, and why?
The tip of each branch being merged. The merge commit records both histories converging, so it points back at both.
Why do rebased commits get new hashes?
A hash is derived from the commit's content plus its parent. Replay gives each commit a new parent, so it's a new commit with a new hash.

Display math block — quadratic formula

x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}

The quadratic formula gives the roots of any polynomial \(ax^2 + bx + c = 0\) where \(a \neq 0\).

Euler's identity

e^{i\pi} + 1 = 0

Often called the most beautiful equation in mathematics, it connects five fundamental constants: \(e\), \(i\), \(\pi\), \(1\), and \(0\).

Normal distribution PDF

f(x) = \frac{1}{\sigma\sqrt{2\pi}} \exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)

The probability density function of a normal distribution with mean \(\mu\) and standard deviation \(\sigma\).

Inline math in prose

The Pythagorean theorem states that in a right triangle, \(a^2 + b^2 = c^2\), where \(c\) is the hypotenuse. For example, a 3-4-5 triangle satisfies \(9 + 16 = 25\).
